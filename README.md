# Компонент "Калькулятор" для Битрикс

![Скриншот калькулятора](docs/screenshot.png)

Универсальный компонент для различных расчетов на сайтах под управлением 1С-Битрикс.

## 📌 Возможности

- Кредитный калькулятор (аннуитетные платежи)
- Депозитный калькулятор (с капитализацией)
- Строительный калькулятор материалов
- Адаптивный дизайн (mobile-friendly)
- Гибкая настройка через параметры
- Поддержка локализации (русский/английский)

## 🚀 Установка

1. Скопируйте содержимое репозитория в:
   ```
   /bitrix/components/custom/calculator/
   ```

2. Добавьте компонент на страницу:
```php
<?$APPLICATION->IncludeComponent(
    "custom:calculator",
    "",
    array(
        "CALCULATOR_TYPE" => "loan",
        "SHOW_RESULTS" => "Y"
    )
);?>
```

## ⚙️ Параметры компонента

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|--------------|----------|
| CALCULATOR_TYPE | string | "loan" | Тип калькулятора (loan/deposit/construction) |
| SHOW_RESULTS | Y/N | "Y" | Показывать блок результатов |
| DEFAULT_AMOUNT | number | 0 | Начальная сумма |
